## Общие положения. Информация о cookie-файлах и встроенных скриптах

Cookie-файлы — это файлы, содержащие небольшой фрагмент текста, предназначенный для запоминания информации о посещении Пользователем Сайта.

Цель использования cookie-файлов — запоминание информации о Пользователе и его предпочтениях для повышения эффективности работы Сайта, а также для получения аналитической информации.

При просмотре любой страницы Сайта на устройство Пользователя загружается сама страница, а также может загружаться небольшой текстовый файл, называемый cookie.

Cookie-файлы, размещаемые на устройстве Пользователя непосредственно Оператором, называются «собственными». Cookie-файлы, размещаемые на устройстве Пользователя иными лицами (в частности, поставщиками аналитических сервисов, действующими по поручению Оператора, либо социальными сетями — при использовании Пользователем кнопок «поделиться»), называются файлами «третьих лиц».

Информация, полученная Оператором посредством собственных cookie-файлов, используется для предоставления Пользователю сервисов Сайта в удобном виде, персонализации опыта использования Сайта, определения наиболее посещаемых страниц и анализа эффективности работы Сайта. Оператор не передаёт содержимое собственных cookie-файлов третьим лицам, за исключением поставщиков аналитических сервисов, действующих по поручению Оператора в целях, указанных в настоящем документе.

Встроенные скрипты — это фрагменты программного кода, включённые в отдельные страницы Сайта, которые собирают статистику использования Сайта (например, какие ссылки нажимает Пользователь). Эта информация используется Оператором для улучшения Сайта и адаптации его содержания к интересам Пользователей.

## Используемые cookie-файлы

По назначению на Сайте используются следующие cookie-файлы:

1. Эксплуатационные cookie-файлы — собирают информацию об использовании Сайта. Не используются для сбора данных, позволяющих идентифицировать Пользователя; собранная информация используется в статистических целях и остаётся анонимной.
    
2. Функциональные cookie-файлы — собирают и запоминают информацию о выборе Пользователя на Сайте (например, настройки Личного кабинета). Не позволяют идентифицировать Пользователя вне Сайта Оператора.
    
3. Аналитические cookie-файлы — используются для оценки посещаемости и эффективности работы Сайта с помощью сервисов веб-аналитики.
    
4. Прочие cookie-файлы — выполняют иные служебные функции, обеспечивающие удобство работы с Сайтом.
    

По времени действия на Сайте используются следующие cookie-файлы:

1. Постоянные cookie-файлы — хранятся на устройстве Пользователя и не удаляются при закрытии браузера; используются для сохранения пользовательских настроек между сеансами использования Сайта.
    
2. Сессионные cookie-файлы — существуют только во время нахождения Пользователя на Сайте и автоматически удаляются при закрытии браузера; позволяют Сайту помнить информацию о действиях Пользователя в рамках одного сеанса, чтобы избежать повторного ввода данных.
    

## Цели использования cookie-файлов

Cookie-файлы используются Оператором в следующих целях:

1. Упростить использование Сайта и повысить эффективность его работы.
2. Обеспечить работу функционала Личного кабинета и Сервиса (авторизация, сохранение настроек).
3. Анализировать посещаемость страниц и иные статистические данные для совершенствования Сайта.
4. Помогать Пользователям в получении необходимой информации о работе Сайта.
5. Определять количество посетителей Сайта и характер его использования для повышения эффективности Сайта.

Сбор статистики использования Сайта Пользователем осуществляется Оператором на постоянной основе с помощью cookie-файлов. Cookie-файлы, используемые Оператором, не содержат персональных данных, позволяющих напрямую идентифицировать Пользователя, и используются преимущественно для целей веб-аналитики.

## Управление cookie-файлами

Чтобы настроить работу с cookie-файлами, следует обратиться к соответствующей функции используемого браузера. Пользователь может:

1. Отключить сохранение cookie-файлов.
2. Ограничить их создание конкретными сайтами.
3. Установить уведомление о создании cookie-файлов в браузере.
4. В любой момент удалить cookie-файлы со своего устройства.

Если Пользователь настроил браузер на полный запрет приёма cookie-файлов, он по-прежнему может посещать Сайт, однако отдельные функции Сайта и Сервиса (в частности, авторизация в Личном кабинете) могут быть недоступны.

## Срок хранения cookie-файлов

Сессионные cookie-файлы действуют с момента входа Пользователя на Сайт до конца соответствующего сеанса работы в браузере и автоматически удаляются при его закрытии.

Постоянные cookie-файлы сохраняются на устройстве Пользователя в течение срока, определяемого их назначением, но не более 12 (двенадцати) месяцев с момента их размещения, если иной срок не указан при их установке.

## Cookie-файлы третьих лиц

На отдельных страницах Сайта могут использоваться кнопки для публикации информации в социальных сетях. При нажатии на такую кнопку соответствующая социальная сеть может создать собственный cookie-файл. Оператор не контролирует использование таких cookie-файлов — за информацией о них следует обращаться к соответствующей социальной сети.

При использовании Сервиса для публикации Контента Пользователя в его Подключённых аккаунтах в социальных сетях такие социальные сети могут независимо от Оператора устанавливать собственные cookie-файлы в рамках работы своих сервисов. Оператор не несёт ответственности за политику и действия таких третьих лиц.
