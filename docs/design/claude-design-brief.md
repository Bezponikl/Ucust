# Бриф для Claude Design — визуал UCust

Этот файл — готовые описания для генерации в **Claude Design** (claude.ai/design). Скорми туда сначала блок «Бренд-контекст», потом нужную сцену. Формат карточек — **4:5**, две темы (светлая/тёмная). Стиль — Apple-уровень: чистая сцена + маленькая история, а не «иконка + текст».

```
Бренд: UCust — ИИ-маркетолог для малого бизнеса (ведёт соцсети за предпринимателя).
Тон: технологично, но тепло. Чисто, много воздуха, скругления 28–32px, glassmorphism.
Шрифт: Manrope (весь текст). Иерархия — кеглем и весом, не сменой шрифта.

Палитра:
- Бренд-синий #4F7DFF (hover #3D63E6), подложка #E6ECFF
- Акценты: purple #7B5CFF, pink #FF5FA2, orange #FF8C4B
- Градиент бренда: linear-gradient(110deg, #4F7DFF, #7B5CFF, #FF5FA2, #FF8C4B) — для «вау»-акцентов, не для больших плоскостей
- Текст #1F2433, приглушённый #6B7280; фон #F2F4F7; карточка #FFF; граница #E6E9F0
- Тёмная тема: фон #0C0E14, карточка #141823

Иконки: стиль Solar (скруглённые, iOS-подобные). Никаких тонких линейных «шаблонных» иконок.
Правила: градиентную заливку заголовков применять редко (2–3 на страницу). Фото — тёплые, живые, без стокового глянца.
```

# Карточки-сюжеты возможностей (6 шт.)

Каждая — мини-история. Даю: **концепт → сцена → движение → настроение**. В конце — готовый промпт.

### 1. Генерация постов — «Одна фраза → готовый пост»
- **Сюжет:** владелец кафе бросает одну фразу — «сегодня свежие круассаны» — и она на глазах расцветает в готовый пост: подпись, тёплое фото выпечки, аккуратные хэштеги собираются по частям.
- **Сцена:** сверху — реплика в «пузыре» рукописного вида; вниз перетекает карточка поста в стекле, фото выпечки в тёплом утреннем свете, ниже — сгенерированная подпись и 3 хэштега-чипа.
- **Движение:** слова из пузыря «рассыпаются» и собираются в блоки поста (морфинг текста → карточка), фото проявляется с лёгким zoom-in.
- **Настроение:** магия «сказал — получил».
```
Карточка 4:5. Сцена «одна фраза превращается в готовый пост».
Сверху рукописная реплика владельца кафе в пузыре. Ниже она морфится в стеклянную карточку
соцпоста: тёплое фото круассанов (утренний свет), подпись Manrope, 3 хэштег-чипа #E6ECFF.
Анимация: слова из пузыря перетекают и собираются в блоки поста; фото проявляется zoom-in.
Палитра бренда, скругления 28px, glass. Светлая и тёмная версии.
```

### 2. Контент-план — «Месяц вперёд за секунды»
- **Сюжет:** пустой календарь на месяц заполняется сам — мини-посты «сдаются» в клетки по датам, как колода карт крупье.
- **Сцена:** сетка календаря (4×7), в клетки влетают миниатюры постов с логотипами каналов в углу; сегодня — подсвечено брендом.
- **Движение:** карточки каскадом падают в клетки (стаггер), лёгкий наклон сетки для глубины.
- **Настроение:** контроль, «всё распланировано».
```
Карточка 4:5. Сцена «календарь заполняется постами сам».
Сетка месяца; мини-посты каскадом влетают в клетки по датам (эффект сдачи карт), у каждого —
значок канала в углу, сегодняшняя клетка подсвечена #4F7DFF. Лёгкий 3D-наклон сетки.
Анимация: стаггер-падение карточек. Палитра бренда, glass, Manrope. Светлая и тёмная.
```

### 3. Автопостинг — «Публикует, пока вы спите»
- **Сюжет:** ночь; из телефона вылетает бумажный самолётик-пост и разлетается ручьями к иконкам VK/TG/MAX/OK — сам, по расписанию.
- **Сцена:** телефон в центре, над ним луна/часы «03:00»; трассы-дуги от телефона к светящимся иконкам каналов.
- **Движение:** самолётик вылетает, делится на несколько трасс, на иконках — «пинг» доставки (расходящийся круг).
- **Настроение:** спокойствие, автономность.
```
Карточка 4:5. Сцена «автопостинг ночью, сам по расписанию».
Телефон по центру, вверху часы 03:00 и полумесяц. Бумажный самолётик-пост вылетает и делится
на дуги-трассы к иконкам VK, Telegram, MAX, OK; на каждой — пинг-круг доставки.
Наш градиент в трассах. Анимация: вылет + разветвление + пинги. Светлая и тёмная.
```

### 4. Акции и промо — «Скидка, которая приводит клиентов»
- **Сюжет:** пост-акция со скидкой запускается — и счётчик «гостей» тикает вверх, летит конфетти.
- **Сцена:** карточка промо с бейджем «−20%», рядом растущий счётчик «+37 клиентов», конфетти в цветах бренда.
- **Движение:** бейдж пульсирует, число счётчика count-up, конфетти-бёрст.
- **Настроение:** праздник, результат.
```
Карточка 4:5. Сцена «промо приводит клиентов».
Стеклянная карточка акции с крупным бейджем −20% (градиент бренда). Рядом счётчик «+37 клиентов»
с анимацией count-up и конфетти в цветах #4F7DFF/#7B5CFF/#FF5FA2/#FF8C4B.
Анимация: пульс бейджа, счёт вверх, конфетти-бёрст. Manrope. Светлая и тёмная.
```

### 5. Отзывы — «Каждый отзыв — с ответом»
- **Сюжет:** приходит отзыв на 5 звёзд, звёзды заполняются, и снизу мягко «печатается» готовый ответ от ИИ.
- **Сцена:** карточка отзыва с аватаром и 5 звёздами; ниже — поле ответа, где по буквам появляется вежливый текст, курсор мигает.
- **Движение:** звёзды заполняются слева-направо; текст ответа печатается (typing).
- **Настроение:** забота, доверие.
```
Карточка 4:5. Сцена «отзыв + готовый ответ ИИ».
Сверху карточка отзыва: аватар, имя, 5 звёзд, заполняющихся слева-направо (#FF8C4B/градиент).
Ниже поле ответа, где по буквам печатается вежливый ответ, мигает курсор.
Анимация: заливка звёзд + typing-эффект. Glass, Manrope. Светлая и тёмная.
```

### 6. Аналитика — «Видно, что работает»
- **Сюжет:** дашборд оживает — линия охвата сама рисуется, столбцы растут, всплывает бейдж «лучший пост недели» со стрелкой вверх.
- **Сцена:** мини-дашборд: линейный график (draw-on), рядом бар-чарт, сверху — карточка «+128% охват» и метка лучшего поста.
- **Движение:** линия рисуется (stroke-dashoffset), столбцы растут снизу, бейдж выскакивает pop-in.
- **Настроение:** ясность, рост.
```
Карточка 4:5. Сцена «аналитика оживает».
Мини-дашборд: линия охвата рисуется сама (draw-on), бар-чарт растёт снизу, всплывает бейдж
«+128% охват» со стрелкой вверх и метка «лучший пост». Градиент бренда в графике.
Анимация: draw-on линии, рост столбцов, pop-in бейджа. Manrope. Светлая и тёмная.
```

# Видео-мокап интерфейса (секция «Продукт» — сразу после Hero)

Заменяет/дополняет центральный экран в `ProductShowcase` (`components/ProductShowcase.tsx` → `ProductMockup`),
там же где сейчас статичный браузер-мокап с календарём. Формат сцены **уже задан** этим компонентом:
скруглённая рамка `24px`, браузерный хром (3 точки), `aspect-[4/5]` на мобиле / `aspect-[16/10]` на десктопе.
Две плавающие карточки рядом (`PostCard`, `ReachCard`) — уже готовые в коде, в видео их дублировать не нужно.

**Сюжет:** «Путь одного поста» — фраза владельца бизнеса на глазах становится опубликованным постом с растущими лайками.
Это самый прямой аргумент «сказал — получил за секунды», ключевой месседж лендинга.

**Технические требования:**
```
Формат: 16:10 (десктоп), с безопасным кропом под 4:5 для мобильной версии.
12 секунд, бесшовный луп (без плеера/контролов — как автовоспроизводящийся GIF, без звука).
Светлая и тёмная версии (токены — см. Бренд-контекст выше).
Рамка: скругление 24px, тонкая граница var(--border), браузерный хром сверху (3 точки) — как в
существующем ProductMockup.tsx, чтобы видео встало в готовую рамку без доработок.
```

**Таймлайн (4 бита по 3 сек, реальный UI + анимационные слои поверх):**

1. **0–3с — Ввод.** База — скриншот блока «Создать пост с ИИ» (поле + 3 кнопки-примера тем, как в
   `InlineAiPrompt.tsx`). Курсор кликает в поле, печатается по буквам фраза «Скидка на завтраки по будням»,
   мигает курсор ввода.
2. **3–7с — Генерация.** Фраза «сворачивается» и морфится в карточку поста (стиль `PostCard`: аватар-бейдж
   U, полоски заголовка, ИИ-бейдж со sparkles, 3 строки текста печатаются по одной, фото проявляется
   zoom-in с градиентом surface-blue→surface-soft).
3. **7–10с — Публикация.** Карточка чуть уменьшается и улетает по дуге вправо к иконке канала
   (VK или Telegram), в момент прилёта — пинг-круг (расходящаяся окружность) и смена бейджа на
   «Опубликовано» с иконкой check.
4. **10–12с — Результат.** Карточка возвращается на место постом с мини-статами снизу: счётчик лайков
   считает вверх (0 → 24) с эффектом count-up, рядом — маленький бар-чарт охвата растёт снизу вверх
   (как в `ReachCard`). Мягкий бренд-глоу под карточкой в конце.
   Плавный кроссфейд на кадр 1 → луп.
```
Анимированная сцена интерфейса, 12 сек, зациклено, без звука. Формат 16:10, скругление 24px, тонкая
светлая/тёмная граница, браузерный хром сверху (3 цветные точки слева).
База — реалистичный экран продукта (не абстрактная иллюстрация): поле ввода ИИ-промпта слева-сверху,
карточка поста по центру.
Таймлайн:
0-3с: курсор кликает в поле «Создать пост с ИИ», печатается по буквам «Скидка на завтраки по будням»,
мигает текстовый курсор.
3-7с: фраза морфится в карточку поста — аватар-бейдж «U», ИИ-бейдж со sparkles, 3 строки подписи
печатаются по очереди, фото проявляется zoom-in (градиент #E9F0FF→#F5F7FA).
7-10с: карточка уменьшается и летит по дуге к иконке соцсети (VK/Telegram) справа, на прилёте —
расходящийся пинг-круг, бейдж меняется на «Опубликовано» (галочка).
10-12с: карточка на месте, снизу count-up счётчик лайков 0→24 и мини-бар-чарт растёт снизу вверх,
мягкое синее свечение под карточкой. Плавный кроссфейд обратно в кадр 0 (бесшовный луп).
Палитра бренда (#4F7DFF основной, градиент в бейджах и глоу), шрифт Manrope, скругления 16-24px,
лёгкий glass-эффект карточек. Светлая и тёмная версии.
```

## Как использовать
1. В Claude Design создай проект, вставь **Бренд-контекст** (или дай ссылку на репозиторий/`tokens.json` — он сам построит систему).
2. Генери карточки по одной промптом из блока сцены; проси **интерактивный HTML** + светлую и тёмную версии.
3. Понравившийся результат (HTML/описание/ассет) кидай мне — я переношу в наши `.tsx`-компоненты (Features/ProductShowcase) с framer-motion, темами и доступностью.
