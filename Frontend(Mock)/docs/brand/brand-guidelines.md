# UCust — Айдентика бренда

**Версия 1.0 · обновлено 02.07.2026**

Полный гайдлайн: [`UCust-brandbook.html`](./UCust-brandbook.html) (интерактивный) и [`UCust-brandbook.pdf`](./UCust-brandbook.pdf) (на печать/рассылку).
Токены для разработки: [`tokens.css`](./tokens.css) · [`tokens.json`](./tokens.json).

UCust — ИИ-маркетолог для малого бизнеса: ведёт соцсети вместо предпринимателя. Визуальный язык — **технологичный, но тёплый**: чистый интерфейс, фирменный синий, стеклянные поверхности, мягкие 3D-иллюстрации.

**Принципы:** Ясность · Технологичность · Теплота · Доступность.

## 01 · Логотип

| Файл | Назначение |
|---|---|
| `public/brand/logo-darktext-4k.png` | Тёмный текст — для светлого фона |
| `public/brand/logo-lighttext-4k.png` | Светлый текст — для тёмного/цветного фона |
| `public/brand/logo-icon.png` | Знак-иконка — favicon, аватары, компактные места |
| `public/brand/app-icon.png` | Иконка приложения |

- **Охранное поле:** не меньше высоты знака «U» вокруг логотипа.
- **Минимальный размер:** леттермарк — 24px (экран) / 10 мм (печать); знак — 16px.
- **Нельзя:** растягивать, наклонять, перекрашивать, добавлять тени/обводки, класть тёмный логотип на тёмный или пёстрый фон.

### Фирменный градиент
`linear-gradient(120deg, #4F7DFF 0%, #7B5CFF 38%, #FF5FA2 72%, #FF8C4B 100%)` — только для акцентных «вау»-моментов (hero, главный CTA), не для больших плоскостей.

### Акценты
`#7B5CFF` Purple · `#FF5FA2` Pink · `#FF8C4B` Orange.

### Статусы
| Роль | Основной | Подложка |
|---|---|---|
| Success | `#18A957` | `#E3F5EB` |
| Warning | `#F5A623` | `#FEF4E1` |
| Error | `#E5484D` | `#FCEBEC` |
| Info | `#2D9CDB` | `#E4F1FB` |

### Палитра для графиков
`#4F7DFF` · `#7B5CFF` · `#FF5FA2` · `#FF8C4B` · `#12B5A5` · `#F5C147` — категориальный набор для аналитики и дашборда.

### Нейтральные (50 → 900)
`50 #F8F9FC` · `100 #F2F4F7` · `200 #E6E9F0` · `300 #D4D9E3` · `400 #B0B7C6` · `500 #6B7280` · `600 #4B5163` · `700 #363B4A` · `800 #272D3B` · `900 #1F2433`
(100 = canvas · 200 = border · 500 = ink-muted · 900 = ink; тёмная тема опирается на 800–900.)

### Доступность
- Основной текст `#1F2433` на светлом — контраст > 12:1.
- На бренд-синем `#4F7DFF` — только белый текст.
- Приглушённый `#6B7280` — от 14px (AA).
- Статусы дублируйте иконкой, а не только цветом.

## 03 · Типографика

Единственная гарнитура — **Manrope** (весь бренд). Иерархия строится кеглем и насыщенностью, не сменой шрифта.

**Начертания:** Regular 400 · Medium 500 · SemiBold 600 · Bold 700 · ExtraBold 800.

| Роль | Размер | Вес | Трекинг |
|---|---|---|---|
| Display | 44–76px | 800 | −3% |
| H1 | 34px | 800 | −2% |
| H2 | 26px | 700 | — |
| Lead | 19px | 500 | — |
| Body | 16px / 1.5 | 400 | — |
| Kicker | 13px, caps | 600 | +14% |
| Caption | 13px | 400 | — |

Подключение: `next/font/google` → Manrope, subsets `latin` + `cyrillic`, weights 400–800. Fallback: `system-ui, sans-serif`. Комфортная длина строки — до 65 символов.

## 04 · Иллюстрации и фото

Три пласта визуала, единая температура — прохладный синий свет с тёплыми акцентами:

1. **3D / glass-иллюстрации** (`public/hero.webp`) — глянцевые объёмы, синее свечение ИИ-сферы, бумажные самолётики-публикации. Прозрачный/градиентный фон, без жёстких краёв.
2. **Плоские фичевые** (`public/features/*.jpg`, + `-dark` версии) — по одной на функцию, светлая и тёмная темы.
3. **Фото-контент** (`public/content/*.jpg`) — естественный свет, реальные сцены малого бизнеса, без стокового глянца. Тёплые тона уравновешивают холодный интерфейс.

**Иконки каналов** (`public/vk.png`, `telegram.png`, `max.png`, `zen.png`, `ok.png`, `whatsapp.png`, `rutube.png`, `avito.png`) сохраняют фирменные цвета площадок — единственное исключение из палитры. Размер и отступы — единые.

## Форма

Скругление карточек: `--radius-card: 32px`, компактных — `--radius-card-sm: 18px`. Стеклянные поверхности (glassmorphism) — фирменный приём для панелей и кнопок.
