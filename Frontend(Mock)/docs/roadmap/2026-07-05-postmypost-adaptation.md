# ЮКаст — Roadmap адаптаций по итогам разбора PostMyPost

**Дата:** 5 июля 2026
**Источник:** конкурентный анализ postmypost.ru / .io (снаружи + вход в интерфейс под аккаунтом)
**Статус:** черновик к обсуждению приоритетов

---

## 1. Стратегическая рамка

| | **PostMyPost** | **ЮКаст** |
|---|---|---|
| Аудитория | Маркетологи, агентства, команды | Владельцы малого бизнеса (не маркетологи) |
| Суть | Мощный ручной SMM-комбайн, власть над деталями | «ИИ ведёт соцсети за тебя» — автопилот |
| Роль ИИ | Аддон по токенам + набор ручных кнопок | Ядро продукта, включён в тариф |
| Сети | 22 | RU-фокус: VK, TG, MAX, OK, Дзен |

**Принцип отбора фич:** берём зрелые UX-паттерны и «тихую» функциональность, которые **усиливают автопилот и упрощают жизнь владельцу**. Не тащим то, что требует навыков маркетолога или ломает простоту.

**Не адаптируем (осознанно):** ручную глубину контроля, роли/права команды, этапы согласования (канбан), токенную оплату ИИ, 22 сети, API/MCP, RSS-репостер.

---

## 2. Легенда оценок

- **Impact:** 🔥 высокий · ➕ средний · ▫️ вспомогательный
- **Effort:** S (≤1 день) · M (2–4 дня) · L (неделя+)
- **Fit:** насколько ложится на позиционирование «ИИ-автопилот»

---

## 3. Фичи по приоритетам

### P0 — ядро дифференциации (делаем первыми)

#### 3.1. Авто-версии поста под каждую сеть (ИИ)
- **Что у PMP:** «+Версия поста» — вручную пишешь свой вариант под каждую соцсеть.
- **Наш ход:** ИИ **сам** адаптирует текст/длину/эмодзи/хэштеги под VK vs TG vs MAX vs OK. Владелец видит вкладки-версии, может подправить.
- **Текущее состояние:** `CreateView` генерит один общий текст на все каналы.
- **Gap:** нет per-channel адаптации и переключения версий.
- **Impact:** 🔥 · **Effort:** M · **Fit:** идеальный (наш козырь vs их ручной труд)

#### 3.2. Live-превью поста под каждую сеть (моб/десктоп)
- **Что у PMP:** правая панель редактора — живое превью, переключатель телефон/десктоп, вкладка «Обсуждение».
- **Наш ход:** превью-панель в «Создать контент», показывает, как пост выглядит в ленте VK/TG/OK; тумблер моб/десктоп.
- **Текущее состояние:** `CreateView` — только медиа-превью карточки, без «как в реальной ленте».
- **Impact:** 🔥 · **Effort:** M · **Fit:** высокий

#### 3.3. Единые «Входящие» + ИИ-черновик ответа
- **Что у PMP:** двухпанельный inbox как почта — Сообщения/Комментарии/Контакты, триаж «Требуется ответ», ответ из Telegram.
- **Наш ход:** объединить разрозненные **Отзывы + Чат-бот** в один раздел «Входящие»; ИИ предлагает готовый черновик ответа в тоне бренда; триаж «нужен ответ».
- **Текущее состояние:** `ReviewsView` (отзывы+ИИ-ответ) и Чат-бот живут отдельно; Чат-бот — заглушка.
- **Impact:** 🔥 · **Effort:** L · **Fit:** высокий

---

### P1 — активация и планирование

#### 3.4. Плавающий онбординг-трекер «N из 3» + инлайн-ИИ на старте
- **Что у PMP:** чеклист «Начало работы» + липкий попап «Завершить настройку 1 из 3» с прогресс-баром по всему app + инлайн-ИИ промпт с кнопкой прямо в шаге.
- **Наш ход:** после онбординга — липкий progress-nudge (Подключить канал → Создать первый пост → Запустить автопостинг); в шаге создания — инлайн ИИ-промпт «опиши — ИИ сделает».
- **Текущее состояние:** онбординг-визард есть, «липкого» трекера прогресса в дашборде нет.
- **Impact:** 🔥 (активация/retention) · **Effort:** M · **Fit:** высокий

#### 3.5. Виды календаря: Неделя / Месяц / «Сетка соцсети»
- **Что у PMP:** Доска(канбан)/День/Неделя/Месяц/**Сетка Instagram** (превью ленты).
- **Наш ход:** к текущему месяцу добавить Неделя + «Сетка» (как будет выглядеть лента VK/OK). Канбан-этапы — пропускаем (агентское).
- **Текущее состояние:** `ContentView` — только месяц (мок-февраль).
- **Impact:** ➕ · **Effort:** M · **Fit:** высокий

#### 3.6. Типы контента Reels / Stories
- **Что у PMP:** табы Post/Story/Reels в редакторе.
- **Наш ход:** у нас уже есть тип «Сторис»; добавить Reels/короткое видео как первоклассный тип (ИИ-сценарий + генерация).
- **Impact:** ➕ · **Effort:** M · **Fit:** высокий

---

### P2 — тихие автоматизации (ИИ делает молча)

Мелкие, но повышают качество автопостинга. Батчем, каждая S:

- **Рубрики/метки постов** — для контент-плана и фильтрации.
- **Шаблоны подписей** — часто вставляемые блоки (контакты, дисклеймер).
- **Авто-хэштеги / UTM / короткие ссылки** — ИИ добавляет по правилам.
- **Вотермарка** — защита фото логотипом.
- **Повторяющиеся публикации** — регулярные посты по расписанию.
- **Аналитика по посту + «лучшее время» / «что зашло»** — простым языком, без ER/ERR-жаргона.

- **Impact:** ➕/▫️ · **Effort:** S каждая · **Fit:** высокий

## 4. Предлагаемая очередность (фазы)

**Фаза 1 — «Умный редактор» (ядро отличия):**
3.1 Авто-версии под сеть → 3.2 Live-превью. Вместе делают «Создать контент» ощутимо мощнее и наглядно демонстрируют ИИ-адаптацию.

**Фаза 2 — «Активация»:**
3.4 Онбординг-трекер + инлайн-ИИ. Быстро поднимает конверсию новичка в первый пост.

**Фаза 3 — «Входящие»:**
3.3 Единый inbox + ИИ-ответ (объединяет Отзывы+Чат-бот). Самая крупная (L), но закрывает целый разрозненный кусок.

**Фаза 4 — «Планирование»:**
3.5 Виды календаря + 3.6 Reels/Stories.

**Фаза 5 — «Полировка»:**
P2 тихие автоматизации батчем + P3 лендинг-блоки.

## 6. Решения (5 июля 2026)

1. **Чат-бот как отдельный раздел — убираем.** Отдельный конструктор диалогов ломает простоту и не нужен владельцу малого бизнеса. Его пользу впитываем во «Входящие» как режим **«ИИ-автоответ»**: ИИ готовит черновик ответа на каждое входящее (владелец одобряет), простые/FAQ может отправлять сам по разрешению. → «Входящие» объединяют **Отзывы + Сообщения + Комментарии** полностью.
2. **Reels/видео — реальная ИИ-генерация на MVP** (не заглушка).
3. **ИИ включён в тариф, токенной модели нет** — ключевое отличие от PMP, не меняем.
4. **Делаем все фазы подряд, старт с Фазы 1**, правки по ходу.

## 7. Порядок исполнения (утверждён)

Фаза 1 «Умный редактор» (3.1 + 3.2) → Фаза 2 «Активация» (3.4) → Фаза 3 «Входящие» (3.3, поглощает чат-бот) → Фаза 4 «Планирование» (3.5 + 3.6, видео с ИИ-генерацией) → Фаза 5 «Полировка» (P2 + лендинг-блоки).
