# Hero: mesh-градиентный шейдер (тема-зависимый) — дизайн

**Дата:** 2026-07-03 · **Статус:** утверждён · **Задача 1 из 2** (веер карточек в «Возможности» — отдельная задача).

## Цель

Заменить текущий Hero-визуал (`/hero.webp` + `HeroArt`, самолётики/ИИ) на полноэкранный
анимированный WebGL-шейдер (mesh-градиент) в фирменных цветах, тема-зависимый
(светлый/тёмный), с сохранением текущих текстов и CTA.

## Компонент-источник

`designali-in/hero-shader` с 21st.dev — обёртка `ShaderBackground` вокруг
`MeshGradient` из `@paper-design/shaders-react` (паттерн «Beautiful Design Experiences»):
полноэкранный canvas с медленно перетекающими цветными «дымками» + SVG-фильтры
(`#gooey-filter`, `#glass-effect`) для стеклянных акцентов.

## Решения (утверждены)

- **Тон:** тема-зависимый — светлый mesh + тёмный текст в светлой теме; тёмный mesh +
  белый текст в тёмной.
- **Макет:** full-bleed фон, контент поверх, текст слева в контейнере (как сейчас).
- **Демо-шапка/навигация и демо-тексты из примера не используются** — свой Navbar и тексты.

## План реализации

### 1. Получение компонента
- Пользователь запускает `npx @21st-dev/cli@beta add designali-in/hero-shader`
  (нужна авторизация 21st.dev — registry закрыт, `{"error":"Authentication required"}`).
- Результат: `components/ui/hero-shader.tsx` (экспорт `ShaderBackground`) +
  зависимость `@paper-design/shaders-react`.
- **Фолбэк**, если авторизация блокирует: установить `@paper-design/shaders-react`
  вручную и написать `ShaderBackground` по тому же публичному паттерну. Итог идентичен.

### 2. Перекраска под бренд + тема-зависимость
- Палитра «дымок» — фирменный градиент `#4F7DFF → #7B5CFF → #FF5FA2 → #FF8C4B`.
- Светлая тема: база `#F5F7FF` + мягкие тинты, тёмный текст.
- Тёмная тема: база `#0A0B14` + насыщенные цвета, белый текст.
- Переключение по классу `.dark` на `<html>` (наш ThemeToggle) через хук с
  `MutationObserver`, чтобы `colors` менялись вживую при переключении темы.

### 3. Встройка в `components/Hero.tsx`
- Секция full-bleed: `ShaderBackground` — фон на всю ширину, min-height ~85vh.
- Контент поверх (z-слой): kicker, `GradientScrollText` h1, подзаголовок, 2 CTA —
  слева в контейнере `max-w-(--container-page)`.
- Убрать `HeroArt`/`/hero.webp` из Hero. Рендер сохранить в `public/` — переиспользуем
  в ProductShowcase (§7 плана).
- Scrim под текстом (радиальное затемнение/высветление по теме) для читаемости.

### 4. Производительность и фолбэки
- Клиентский компонент; динамический импорт с `ssr: false`, монтаж после гидрации —
  против hydration mismatch (известная гоча проекта с анимациями).
- `prefers-reduced-motion` → статичный CSS-градиент вместо canvas (без GPU/анимации).
- Узкие экраны: при необходимости снизить детализацию/скорость шейдера.
