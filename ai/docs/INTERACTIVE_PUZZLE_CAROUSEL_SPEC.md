# UCust AI: Спецификация интерактивных постов-пазлов (Interactive Multi-Slider Cryptex / Mix & Match Puzzle)

## 1. Концепция и фундаментальный принцип

**Interactive Multi-Slider Puzzle (Mix & Match)** — это интерактивный игровой формат в Telegram, где каждая горизонтальная полоса (слой) представляет собой отдельную карусель с возможностью независимого свайпа/вращения.

### 🌟 Принцип полной генерации и гибких якорей:
1. **Генерация целостных картин (Full-Frame Consistency):** Каждая базовая сцена генерируется как полноценная, живая фотография (Full Scene $1024 \times 1024$ px), а не изолированные оторванные куски.
2. **Все слои могут быть интерактивными каруселями:** Первый слой (фон / персонаж / окружение) не обязан быть строго статичным — в нем тоже могут меняться варианты.
3. **Физический якорь (Grounding Base Anchor):** Чтобы при любых комбинациях (когда пользователь свайпает 1, 2, 3 и 4 слои) сцена не рассыпалась, фиксируется **геометрический якорь**:
   - Единая центральная вертикальная ось объекта (Center Axis $X = 50\%$).
   - Единая плоскость горизонта и точки опоры стола (Ground Plane на нижнем слое).
   - Единый угол наклона камеры (Pitch = $30^\circ - 35^\circ$) и фокусное расстояние (50mm / 85mm).

## 2. Матрица нишевых шаблонов (Presets)

### ☕ 1. Specialty Coffee (Кофейный конструктор настроения)
- **Хук / CTA:** *«Свайпай ряды и собери свой идеальный (или самый безумный) кофейный муд на сегодня! Скидывай скриншот в комменты 👇»*
- **Слои:** (Бариста в фартуке / Уютный зал) + (Крышка / Латте-арт / Трубочка) + (Бумажный стакан / Кружка / Советский складной) + (Дубовый стол / Стойка).

### 💅 2. Beauty & Nail Art (Нейл-конструктор образа)
- **Хук / CTA:** *«Собери весенний сет под свое настроение за 3 свайпа! Какой вариант получился у тебя?»*
- **Слои:** (Кашемировый манжет) + (Микро-глиттер / Сатин / Шоколадный френч) + (Нюд / Миндаль / Кольца) + (Шелк и травертин).

### ⚖️ 3. Legal & Corporate Law (Анатомия безупречной сделки)
- **Хук / CTA:** *«Из каких уровней складывается правовая неуязвимость бизнеса? Свайпайте слои и оцените баланс защищенности вашей компании. Напишите в комментариях, какой аспект сейчас в приоритете 👇»*
- **Слои:**
  - **Слой 1 (Top/Статус):** Партнер бюро в темно-синем костюме / Панорамная переговорная Москва-Сити / Зал с дубовыми панелями.
  - **Слой 2 (Документ):** Прошитый договор M&A с красным сургучом / Досье налогового аудита / Арбитражное мировое соглашение.
  - **Слой 3 (Атрибут):** Перьевая ручка `Montblanc Meisterstuck` / Папка из зернистой телячьей кожи / Латунная печать адвоката.
  - **Слой 4 (Якорь):** Стол из мореного дуба / Изумрудный мрамор / Полированный орех.

### 🏦 4. Private Banking & Wealth Management (Архитектура портфеля)
- **Хук / CTA:** *«В управлении капиталом решает гармония базы, ликвидности и активов роста. Прокрутите слои и соберите ваш целевой профиль на 2026 год. Какая стратегия ближе вам?»*
- **Слои:**
  - **Слой 1 (Горизонт):** Панорамный финансовый скайлайн / Кабинет с терминалом Bloomberg / Пентхаус-терраса.
  - **Слой 2 (Класс активов):** Слиток золота 999.9 на синем бархате / Суверенные облигации / Венчурный фонд.
  - **Слой 3 (Инструмент):** Металлическая карта `Private Banking Black Metal` / Швейцарский хронограф / Биометрический ключ.
  - **Слой 4 (Опора):** Матовый черный гранит / Массив тикового дерева / Белый мрамор `Carrara`.

## 3. Математика нарезки и линии швов (Seam Coordinates)

```
Y = 0%   ------------------------------------------------------------
         СЛОЙ 1: Фон, окружение, плечи/торс персонажа, атмосфера (0-22%)
Y = 22%  --- ЛИНИЯ ШВА 1 (Верхняя кромка объекта / воздух) ----------
         СЛОЙ 2: Верхняя часть / Крышка / Латте-арт / Документ (22-44%)
Y = 44%  --- ЛИНИЯ ШВА 2 (Окружность стыка / Главная деталь) --------
         СЛОЙ 3: Тело объекта / Рука / Атрибут / Аксессуар (44-76%)
Y = 76%  --- ЛИНИЯ ШВА 3 (Линия касания объекта и поверхности) ------
         СЛОЙ 4: Опорный стол, постамент, падающая тень (76-100%)
Y = 100% ------------------------------------------------------------
```

## 4. Оптические требования к рендеру (Cinematography Director Standards)

1. **Фокусное расстояние:** 85mm Prime (отсутствие бочкообразных искажений на линиях швов).
2. **Угол наклона камеры (Pitch):** Строго $30^\circ - 35^\circ$ вниз к плоскости стола.
3. **Освещение (Lighting):** Мягкий рассеянный дневной свет (5600K) слева-сверху, создающий естественные глубокие тени.
4. **Аналоговая текстура:** Единое зерно `Kodak Portra 400 ISO 400:1.15` на всех слоях.
