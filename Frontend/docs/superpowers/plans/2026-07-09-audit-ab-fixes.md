- [ ] **Step 3: Strip the numeric dates from the content-plan scene only (scripted)**

Create `scripts/abstract-content-plan-calendar.mjs`. It loads the file, isolates the `content-plan` scene object substring (from its key to the start of the next scene key `"autopost":`), and inside that slice **only**, blanks the date-number spans — turning verifiable dates into empty cells, keeping the weekday header. This keeps the visual grid but removes anything a viewer can check against a real month (matches the approved "abstract calendar" decision in the spec).

```js
import fs from "node:fs";

const path = "components/features/scenes.data.ts";
let src = fs.readFileSync(path, "utf8");

const start = src.indexOf('"content-plan": {');
const end = src.indexOf('"autopost":', start);
if (start === -1 || end === -1) throw new Error("content-plan scene not found");

let scene = src.slice(start, end);

// Blank the day-number text nodes: >12< -> ><  (only 1-2 digit standalone spans).
// The date spans in this scene are of the form >\d{1,2}< inside their own span.
const before = scene;
scene = scene.replace(/>(\s*\d{1,2}\s*)</g, "><");

if (scene === before) {
  console.warn("No date-number spans matched — inspect the scene HTML manually before proceeding.");
} else {
  src = src.slice(0, start) + scene + src.slice(end);
  fs.writeFileSync(path, src, "utf8");
  console.log("content-plan calendar dates blanked.");
}
```

Run: `node scripts/abstract-content-plan-calendar.mjs`
Expected: `content-plan calendar dates blanked.`

> ⚠️ The `>\d{1,2}<` pattern may also match non-date numbers inside the same scene (e.g. a "7 постов" badge). After running, **screenshot again** (Step 5) and confirm only the calendar dates were removed. If unrelated numbers vanished, revert from backup and tighten the regex to the calendar's specific `data-dc-tpl` wrapper seen in the screenshot's DOM (inspect via Playwright `browser_evaluate` to read the exact span markup before re-running).
