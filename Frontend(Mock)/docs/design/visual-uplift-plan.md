## 1. 🚩 Скролл-заполняющиеся заголовки (флагманская фича)

**Что это:** заголовок отрисован тёмным (`--ink`), и по мере попадания в вьюпорт заливается фирменным градиентом слева-направо (по словам/строкам), как у Apple.

**Как делаю (🟦):** новый компонент `components/GradientScrollText.tsx`.
- Техника: CSS **scroll-driven animations** (`animation-timeline: view()`) — без JS, нативно, Chrome 115+/Edge/Safari TP. Текст = слой с `background: var(--gradient-brand); background-clip: text; color: transparent;`, поверх — «шторка» цвета `--ink`, которая уезжает (`clip-path`/`mask`) в такт `view()`-таймлайну.
- **Фолбэк:** для Firefox/старых браузеров и `prefers-reduced-motion` — сразу показываем залитый градиентом заголовок (без анимации). Уже есть глобальный `@media (prefers-reduced-motion)` — впишусь туда.
- Вариант заливки: по словам (per-word стаггер) для крупных H2, целиком — для мелких.
- API: `<GradientScrollText as="h2" fill="word|line|whole">…</GradientScrollText>`.

**Где применяем:** H1 в Hero (частично — слово «ИИ» уже градиентное, расширим), заголовки секций How/Features/Channels/Pricing/FAQ/FinalCta, заголовки на странице «О нас».

🟩 **Решение:** заливка per-word (живее, ближе к Apple) или целиком (спокойнее)? Рекомендую **per-word** для крупных, целиком — для мелких.
