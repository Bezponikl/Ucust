# Экраны настроек: профиль бизнеса + настройки аккаунта

Дата: 2026-07-02

## Цель

Добавить два новых экрана настроек в дашборд UCust и точки входа к ним:

1. **Профиль бизнеса** (`/dashboard/business`) — редактирование данных конкретного бизнеса.
2. **Настройки аккаунта** (`/dashboard/account`) — личные данные пользователя, уведомления, безопасность.

Плюс доработать переключатель бизнеса (шире + шестерёнка) и меню профиля (пункт «Настройки»).

Figma-фрейм (единая страница «Настройки» с 6 вкладками) — **общий пример**, не эталон. Реализуем в стилистике проекта: карточки-секции на одной странице, а не вкладки.

## Не-цели (YAGNI)

- **Нет** бэкенда/персистентности: всё визуальное, локальный стейт + фидбэк «Сохранено» (как остальной прод-демо).
- **Tone of Voice убран** полностью (по решению пользователя).
- Никаких вкладок сверху — только секции-карточки.
- Не трогаем существующие разделы (Контент, Акции, Отзывы, Аналитика).

## Точки входа и навигация

- **Меню профиля** (`ProfileMenu`, аватар в топбаре): добавить пункт **«Настройки»** (иконка `Settings`) → `/dashboard/account`. Остальные пункты (тема на мобиле, Правовое, Выйти) без изменений; «Настройки» ставим над блоком «Правовое».
- **Переключатель бизнеса** (`ProjectSwitcher`):
  - Кнопку удлинить: `max-w-[200px]` → шире (десктоп `sm:max-w-[240px]`, мобилка `max-w-[220px]`), чтобы длинные названия влезали.
  - В выпадающем списке у каждой строки бизнеса справа — **иконка-шестерёнка** (`Settings`, размер 16, `text-ink-muted hover:text-brand`). Клик по шестерёнке: выбрать этот бизнес + перейти на `/dashboard/business?id=<id>` (навигация через `router.push`, `stopPropagation` чтобы не сработал выбор строки). Клик по самой строке — прежнее поведение (выбор + закрытие).

## Данные (мок)

Новый модуль `lib/dashboard/businesses.ts`:

```ts
export interface SocialLink { id: ChannelId; connected: boolean; }
export interface BusinessProfile {
  id: string;
  name: string;
  logo?: string;          // путь/blob; по умолчанию нет — показываем инициал
  category: string;       // сфера деятельности
  address: string;
  phone: string;
  site: string;
  description: string;
  workStart: string;      // "09:00"
  workEnd: string;        // "18:00"
  daysOff: number[];      // 0..6 (Пн..Вс)
  socials: SocialLink[];  // по каждому каналу из CHANNEL_ORDER
}
export const BUSINESSES: BusinessProfile[];      // 2-3 мок-бизнеса (совпадают со списком переключателя)
export function getBusiness(id?: string): BusinessProfile;  // по id или первый
```

`ProjectSwitcher` переводим со строкового `MOCK_PROJECTS` на `BUSINESSES` (id + name + initial). Текущее имя берём из `DashboardProvider` (businessName) как заголовок первого/активного.

Настройки аккаунта — локальные мок-значения прямо в компоненте (имя «Анна Иванова», email и т.д.), без отдельного модуля (одна страница, один пользователь).

## Экран: Профиль бизнеса (`/dashboard/business`)

Клиентский компонент `components/dashboard/business/BusinessSettings.tsx`, страница `app/dashboard/business/page.tsx`. Читает `?id` (через `useSearchParams` в Suspense-безопасном виде — как в ContentView, из `window.location`) → `getBusiness(id)` в初 initial state.

Секции (карточки `rounded-[24px] border bg-card`, как везде):

1. **Шапка бизнеса**: круглый логотип (или инициал на `bg-brand-tint`), кнопки «Загрузить» (file input, blob-preview) / «Удалить»; рядом — название (крупно) и сфера (подпись).
2. **Основное**: Название компании, Сфера деятельности (`<select>`), Адрес, Телефон, Сайт — сетка 2 колонки; Описание бизнеса (`<textarea>`, на всю ширину). Поля с иконкой-карандашом (декоративной), фокус-стили как в проекте.
3. **Часы работы**: Время начала / Время окончания (простые time-инпуты или `<select>` со слотами из `schedule.tsx` при наличии); Выходные дни — 7 чекбоксов Пн–Вс (тоггл по клику, стиль как чекбоксы канала).
4. **Соцсети бизнеса**: строки по каналам (`CHANNEL_ORDER`): иконка канала + название + статус. Подключён → «Подключено» (зелёный) + «Редактировать» + «Отключить» (красный). Не подключён → кнопка «Подключить». Мок-переключение состояния локально.
5. **Действия**: «Сохранить изменения» (`btn-glass-blue`, мок → «Сохранено» на 0.65s); ниже, отдельной строкой, «Удалить бизнес» (текст/кнопка danger, `text-red-…`, при мок-клике просто confirm-нет-действия или переход на дашборд).

## Экран: Настройки аккаунта (`/dashboard/account`)

Клиентский `components/dashboard/account/AccountSettings.tsx`, страница `app/dashboard/account/page.tsx`.

Секции:

1. **Шапка профиля**: аватар (инициалы `АИ` или загруженное фото), «Загрузить»/«Удалить»; рядом — отображаемое имя. **Отображаемое имя = `Фамилия Имя Отчество`, но отчество показываем только если поле заполнено** (пустое отчество → «Фамилия Имя»).
2. **Профиль**: Фамилия, Имя, Отчество, Должность, Email, Телефон. «Сохранить».
   - Поля Имя/Фамилия/Отчество повторяют форму регистрации (`SignupModal`), где Отчество — с подписью «(не обязательно)». Поле **всегда присутствует и редактируемо**: пустое, если отчество не указано, с возможностью заполнить.
3. **Уведомления**: две группы чекбоксов — Email-уведомления и Push-уведомления (Новые отзывы, Завершение публикации, Критичные вопросы в чат-боте, Еженедельный отчёт). Локальный стейт.
4. **Безопасность**:
   - Смена пароля: Текущий / Новый / Повтор нового (`type=password`), кнопка «Обновить пароль».
   - Двухфакторная аутентификация: тумблер (переиспользуем стиль тоггла темы/переключателя).
   - Активные сессии: список карточек (устройство, ОС, город, время + иконка «выйти»); кнопка «Выйти со всех устройств».

## Стилистика

- Наследуем существующие токены/классы: `rounded-[24px]`, `border-border`, `bg-card`, `bg-surface-soft`, `btn-glass-blue`, `text-ink/-muted`, фокус `focus:border-brand focus:ring-2 focus:ring-brand-tint`.
- Заголовок каждой страницы: `h1` «Профиль бизнеса» / «Настройки аккаунта» + подпись (как на других экранах дашборда).
- Пункты навигации активны через существующий `isNavActive`, но эти страницы **не** в сайдбаре (вход только через меню/шестерёнку) — так решили.
- Danger-элементы: красный акцент (`text-red-500` / `hover:bg-red-500/10`).
