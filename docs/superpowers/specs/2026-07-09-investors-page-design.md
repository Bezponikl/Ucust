# UCust — страница для инвесторов `/investors`

**Дата:** 2026-07-09
**Статус:** утверждён к реализации
**Ветка:** `investors-page`

## Контекст

Нужна отдельная страница для потенциальных инвесторов: краткий питч + контакт. Точка входа — футер главной, колонка «Компания», где пункт «Вопросы» заменяется на «Инвесторам». Контент берётся из стартап-питча (`C:\Claude\Presentation Startup\_pitch.txt`), **без региональной привязки** (не упоминать Ростовскую область и региональные агентства — масштаб федеральный).

Решения пользователя:
- Формат: **отдельная страница** `/investors` (не модалка), по паттерну `about`/`legal`.
- Глубина: **краткий питч + контакт** (не полный data-room).
- Форма: **сторонний сервис Web3Forms** (без бэкенда; заявки на `ucust@yandex.ru`).
- Плюс кнопка **«Скачать презентацию»** — пока конкурсная `UCast_Startup_v2.pptx` (потом заменится на инвест-версию/PDF).

### 2. Данные — `lib/investors.ts`
Декларативный источник контента, чтобы страница была чистой. Реальные тезисы из питча (без региона):
- **Суть:** автономный ИИ-маркетолог для малого бизнеса; от 1 500 ₽/мес — в 10–20 раз дешевле штатного специалиста.
- **Проблема:** штатный маркетолог 40–80 тыс., агентство до 100 тыс. — неподъёмно для микробизнеса; 61% ведут маркетинг сами, больше половины не знают, что публиковать, у 60% посты не приводят клиентов.
- **Решение:** анкета за пару минут → платформа анализирует бизнес, строит контент-план на месяц, генерирует пост по фразе (текст+картинка) и сама публикует в удачное время (учёт отрасли/сезонности).
- **Рынок:** интернет-реклама РФ — 1 569 млрд ₽ (×6 за 5 лет); сегмент МСБ — 1 120 млрд ₽; реально достижимый (SAM) — 189 млрд ₽; 62% организаций уже работают с ИИ-агентами.
- **Метрики (плитки):** рабочий прототип · 2 свидетельства Роспатента (2026) · 89% в CustDev готовы доверить маркетинг ИИ · ARPU 3 300 ₽/мес · валовая маржа до 80% · LTV/CAC 3,47 (окупаемость CAC ~3,5 мес).
- **Технология-барьер:** 6 ИИ-агентов, автономный полный цикл (на рынке РФ аналога нет), отечественные модели, данные в России по 152-ФЗ.
- **Признание/тяга:** победа на инвестиционном форуме, 5 писем поддержки, апробация на компаниях-партнёрах. (Без названий региональных структур.)
- **Команда:** полного цикла — продукт, ML- и full-stack-разработка, проджект-менеджмент, научное сопровождение; за плечами запуск ИИ-продуктов, стажировки, победы на хакатонах.
- **Roadmap:** Q3 — MVP → пилотные клиенты к концу года → 2027 — коммерческий запуск → 2028 — масштабирование и операционная прибыль.
- **Запрос (мягкая формулировка для публичной страницы):** «Открыты к диалогу с инвесторами и партнёрами для масштабирования» — без конкретных сумм гранта.

### 4. Форма — `components/investors/InvestorContactForm.tsx` (`"use client"`)
**Пока без бэкенда и без зарубежных сервисов** (реальная серверная отправка — позже, когда появится бэк). Никаких секретов/ключей/внешних API.
- Поля: имя, email, сообщение. Валидация email на blur; inline-ошибки под полями; лейблы видимые; кнопка ≥44px (ui-ux-pro-max §8).
- Отправка (заглушка, но честная — не показывает ложный «успех»): при сабмите собирается `mailto:ucust@yandex.ru?subject=Инвестиции — UCust&body=<Имя, email, сообщение>` и открывается почтовый клиент пользователя (`window.location.href = mailto…`). Так заявка реально доставляется без бэкенда. После открытия — короткая подсказка «Откроется ваш почтовый клиент. Если не открылся — напишите на ucust@yandex.ru».
- Логика отправки вынесена в одну функцию `submitLead(data)` (сейчас — mailto), чтобы позже заменить на серверный `POST` без переписывания UI.
- Рядом с формой — **прямой email `ucust@yandex.ru` крупным видимым текстом** как надёжный запасной путь (основной рабочий контакт, пока форма на mailto).
