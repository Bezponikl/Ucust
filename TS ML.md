# 1. Общая концепция

Система реализует принцип минимального входа: пользователь предоставляет только URL сайта компании. Все остальные данные извлекаются автоматически из открытых источников.

Цель системы — сформировать полную цифровую модель бизнеса, включающую:

- характеристики компании;
- продукты и услуги;
- целевую аудиторию;
- клиентское восприятие;
- текущую маркетинговую активность.

На основе этой модели система принимает решения и формирует маркетинговые действия.

---

# 2. Источники данных

Система должна работать с тремя основными группами источников:

1. Сайт компании (основной источник)
2. Социальные сети
3. Геосервисы и карты (отзывы и рейтинги)

---

# 3. Сбор данных с сайта (Website Crawling & Extraction)

## 3.1.1 Ручное заполнение

- Анализ информации от клиента(Текст)
- Анализ файлов от клиента (PDF,PPTX,WORDX)

## 3.1 Обязательные страницы для анализа

- Главная страница
- О компании / About
- Услуги / Каталог / Продукты
- Страницы отдельных товаров/услуг
- Блог / Новости (если есть)
- Контакты

## 3.2 Извлекаемые данные

### 3.2.1 Общая информация о бизнесе

- название компании
- описание деятельности
- ключевые формулировки позиционирования (УТП)
- география (город, регион)
- контактные данные (телефон, email)

### 3.2.2 Продукты и услуги

Для каждого товара/услуги:

- название
- описание
- категория
- цена (если указана)
- ключевые характеристики
- преимущества (из текста)

### 3.2.3 Маркетинговые сигналы

- заголовки (H1, H2)
- повторяющиеся формулировки
- призывы к действию (CTA)
- стиль текста (формальный, продающий, экспертный)

### 3.2.4 Визуальный контекст (метаданные)

- наличие изображений товаров
- тип визуала (продуктовый, lifestyle, инфографика)

---

# 4. Сбор данных из социальных сетей (Social Media Extraction)

## 4.1 Платформы (минимум)

- Instagram
- VK
- Telegram
- (опционально: TikTok, YouTube)

## 4.2 Извлекаемые данные

### 4.2.1 Профиль

- описание профиля
- количество подписчиков
- частота публикаций

### 4.2.2 Контент

Для последних N постов (например, 20–50):

- текст поста
- дата публикации
- тип контента (продающий, информационный, развлекательный)
- наличие CTA

### 4.2.3 Метрики вовлеченности

- лайки
- комментарии
- просмотры (если доступны)

### 4.2.4 Комментарии

- текст комментариев
- частотные вопросы
- жалобы и возражения

---

# 5. Сбор данных с карт и агрегаторов (Maps & Reviews)

## 5.1 Источники

- Google Maps
- Яндекс.Карты
- 2GIS (если доступно)

## 5.2 Извлекаемые данные

### 5.2.1 Общая информация

- рейтинг
- количество отзывов
- категория бизнеса
- адрес

### 5.2.2 Отзывы

Для каждого отзыва:

- текст
- оценка (звезды)
- дата
- ответы компании (если есть)

---

# 6. Агрегация данных (Data Fusion)

После сбора данные объединяются в единую структуру.

Необходимо:

- сопоставить продукты с упоминаниями в отзывах
- сопоставить контент соцсетей с позиционированием сайта
- устранить дублирование информации

Результат:  
единая модель бизнеса, включающая:

- профиль компании
- каталог продуктов
- массив отзывов
- массив контента

---

# 7. Аналитический блок (Analysis)

На основе собранных данных необходимо определить:

## 7.1 Целевая аудитория

Определяется на основе:

- языка сайта
- содержания отзывов
- тематики контента

Результат:

- сегменты аудитории
- основные потребности

## 7.2 Боли клиентов (Pain Points)

Из отзывов и комментариев:

- негативные повторяющиеся темы
- частые жалобы

## 7.3 Преимущества бизнеса

- положительные повторяющиеся оценки
- уникальные характеристики

---

# 8. Формирование стратегии (Strategy Generation)

На основе анализа формируется:

- позиционирование
- ключевые сообщения
- контентные рубрики
- частота публикаций
- каналы продвижения

---

# 9. Генерация контента (Content Generation)

Формируется контент-план:

Для каждой единицы контента:

- тема
- текст поста
- тип контента
- CTA
- Визуал(Фото/Видео)

---

# 10. Публикация (Execution)

Система должна:

- планировать публикации
- отправлять контент в соцсети через API
- фиксировать статус публикации

---

# 11. Анализ обратной связи (Feedback Loop)

Система повторно собирает:

- комментарии
- вовлеченность
- реакцию аудитории

И обновляет:

- стратегию
- контент
